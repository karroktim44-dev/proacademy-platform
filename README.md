# ProAcademy | Elite Skill Platform

A premium, single-file responsive web application featuring the world's top 26 most demanding skills across 5 career categories.

## 🎯 Features

### 1. **Dark/Light Theme Engine**
   - Toggle button in sticky navbar
   - Theme preference persisted via localStorage
   - Smooth CSS variable-based transitions

### 2. **Interactive Search & Filter**
   - Real-time course search bar
   - Category filter buttons (All, English & Communication, Freelancing & Agency, IT & Coding, Creative Design, Business Growth)
   - Instant result count display
   - Comprehensive course metadata filtering

### 3. **Premium Modal Course Viewer**
   - Responsive YouTube frame embedding
   - Course details panel (category, level, duration, instructor)
   - Sleek gradient backgrounds and shadow elevations

### 4. **Certification Quiz & Assessment**
   - Multi-choice questions per course
   - Instant verification feedback
   - "🔁 Retake Quiz" button on incorrect answers
   - Success/error status messaging

### 5. **Institutional Digital Certificates**
   - Dynamic certificate generation after passing quiz
   - Student name mapping
   - Course name rendering
   - Issue date tracking
   - Print and PDF save functionality

### 6. **Student Database Registry**
   - "ফ্রি স্টুডেন্ট আইডি অ্যাক্টিভেশন" Bengali capture box
   - 11-digit mobile number validator
   - Mock server fetch hook with success/error handling
   - Student ID generation simulation

## 🚀 Usage

1. **Open** `index.html` in any modern browser
2. **Search** for courses by skill name or category
3. **Click** "Open Course" to view details & embedded video
4. **Launch** the certification quiz
5. **Answer** the multi-choice question
6. **Pass** to unlock institutional certificate (or retake)
7. **Register** as a student with 11-digit mobile validation
8. **Toggle** dark/light theme via navbar button

## 🔧 Technical Stack
